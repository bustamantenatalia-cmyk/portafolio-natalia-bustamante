# Portafolio | Natalia Bustamante

Portafolio profesional desarrollado para presentar los principales proyectos realizados durante mi formación en Desarrollo Full Stack Java.

## Sobre este portafolio

Este sitio reúne proyectos en los que he aplicado conocimientos de desarrollo de software, programación orientada a objetos, bases de datos relacionales, desarrollo web y construcción de aplicaciones utilizando Java y Spring Boot.

## Proyectos destacados

### AlkeWallet
Diseño e implementación de una base de datos relacional para una billetera digital, orientada a la administración de usuarios, monedas y transacciones.

**Tecnologías:** MySQL, SQL y MySQL Workbench.

### Biblioteca Digital UNTEC
Aplicación web desarrollada en Java para la administración de libros, incorporando inicio de sesión, manejo de sesiones, conexión con MySQL y operaciones CRUD.

**Tecnologías:** Java, JSP, Servlets, JDBC, MySQL y Tomcat.

### SpringEduManager
Sistema web para la gestión de alumnos desarrollado con Spring Boot, incorporando control de acceso por roles, operaciones CRUD, búsquedas, validaciones y API REST.

**Tecnologías:** Java, Spring Boot, MySQL y REST API.
