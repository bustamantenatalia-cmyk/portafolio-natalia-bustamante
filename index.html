CASO DE ESTUDIO

SpringEduManager

Sistema de Gestión de Alumnos desarrollado como proyecto final utilizando Java, Spring Boot y MySQL.

Ver proyecto en GitHub
01

El desafío

Desarrollar una aplicación web que permitiera gestionar información de alumnos y diferenciar las funcionalidades disponibles según el rol del usuario.

02

La solución

Se desarrolló un sistema utilizando Spring Boot y MySQL que permite registrar, consultar, modificar y eliminar alumnos mediante una interfaz web.

03

Control de acceso

Se implementaron roles de usuario para diferenciar los permisos. El administrador puede crear, editar y eliminar registros, mientras que el usuario dispone de funciones principalmente orientadas a la consulta.

04

Funcionalidades

  • Registro de alumnos.
  • Listado de alumnos.
  • Búsqueda por RUT.
  • Búsqueda por apellido.
  • Edición de información.
  • Eliminación de registros.
  • Validación de formularios.
  • Control de acceso por roles.
  • API REST.
05

Tecnologías utilizadas

Java Spring Boot MySQL HTML CSS REST API Git
06

Resultado

Se obtuvo una aplicación funcional para la gestión de alumnos, con persistencia de datos, distintos niveles de acceso y operaciones CRUD disponibles desde una interfaz web.

07

Aprendizajes

Este proyecto permitió integrar los conocimientos adquiridos durante el bootcamp y comprender mejor la relación entre la interfaz web, la lógica de la aplicación, la base de datos y el control de acceso.

08

¿Por qué elegí este proyecto?

Elegí SpringEduManager como caso de estudio porque reúne diferentes áreas trabajadas durante mi formación: programación Java, desarrollo web, bases de datos, operaciones CRUD, seguridad por roles y servicios REST.
